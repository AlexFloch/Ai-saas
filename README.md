# Synthos — лендинг AI-сервиса

Адаптивный лендинг вымышленного сервиса для написания текстов с помощью ИИ. Учебный проект: названия, цифры и отзывы на странице вымышленные.

**Демо:** [ai-saas-seven-taupe.vercel.app](https://ai-saas-seven-taupe.vercel.app/)

## Что на странице

- Первый экран с демо-окном примера работы сервиса
- Блок возможностей
- Шаги работы («как это работает»)
- Тарифы
- Отзывы
- Навигация по разделам страницы

## Технологии

- React 18
- Vite
- Tailwind CSS

## Запуск локально

```bash
git clone https://github.com/AlexFloch/ai-saas.git
cd ai-saas
npm install
npm run dev
```

Сайт откроется по адресу, который покажет терминал (обычно `http://localhost:5173`).
